# M2 on-device acceptance tests

Run on one phone with the debug APK from CI. All steps use **Device check → Capture test (M2)**
unless stated. Record the numbers shown on screen in the table at the end.

| #   | Criterion (DEV_PLAN M2, interim policy 007)                                                                         | How                                                                                                                                                                                                                                                                                                                                       |
| --- | ------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Recording isolated from analysis: with a 40 ms analysis delay, effective fps ≥ 29.5 (60 fps target where supported) | Test **FT**, tick _Inject 40 ms analysis delay_, Takes = **5**, Record. All takes PASS; note min fps and max dropped %.                                                                                                                                                                                                                   |
| 2   | Duration = durationS ± 50 ms in 20/20 takes, including with JavaScript frozen                                       | Test **FT**, Takes = **20**, Record (≈ 6 min). Then tick _Freeze JavaScript_, Takes = **5**, Record. All PASS; note max duration error.                                                                                                                                                                                                   |
| 3   | MP4 frame count = frames.bin count (± 1)                                                                            | Shown per take as `MP4 n / frames.bin n` (✓).                                                                                                                                                                                                                                                                                             |
| 4   | Mapped MP4 timestamps within 2 ms of canonical                                                                      | Shown per take as `Δt … ms` (✓). Note how many takes say `earliest_candidate`.                                                                                                                                                                                                                                                            |
| 5   | `video.mp4.enc` copied off the device does not play                                                                 | Per take `encrypted ✓` (the app tries to open it). Optional by hand: `adb shell run-as com.neurocapture.app ls -R no_backup/takes` then `adb exec-out run-as com.neurocapture.app cat no_backup/takes/<takeId>/video.mp4.enc > x.mp4` — it must not play.                                                                                 |
| 6   | In-app playback works                                                                                               | Tap **Play** on a take; the video plays; Close.                                                                                                                                                                                                                                                                                           |
| 7   | Process kill during recording leaves no plaintext after the next start                                              | Start a 30 s **SAW** take, then `adb shell am force-stop com.neurocapture.app` (or swipe the app away) mid-take. Reopen → Device check → Capture test: a yellow _Recovered after a crash_ note lists the take. Check: `adb shell run-as com.neurocapture.app ls no_backup/takes/<takeId>` shows only `*.enc`, `datakey.enc`, `RECOVERED`. |
| 8   | Sharpness calibration                                                                                               | Point at a still, textured target, tap **Sharpness 3 s**; a baseline is shown.                                                                                                                                                                                                                                                            |
| 9   | 30 fps fallback                                                                                                     | On a phone without 1080p60, FT takes show `@ 30` and still PASS.                                                                                                                                                                                                                                                                          |
