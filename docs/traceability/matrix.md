# Requirements traceability matrix

A biomarker counts as **supported** only when all five columns are defined and its acceptance test passes (DEV_PLAN §11). Until biomarker definitions arrive, each test has one row per biomarker family. When a definition arrives, add one row per biomarker ID.

| Biomarker (family)                      | Capture requirement                                                   | Quality rule(s)                                                   | Persisted evidence                            | Acceptance test                                          | Status      |
| --------------------------------------- | --------------------------------------------------------------------- | ----------------------------------------------------------------- | --------------------------------------------- | -------------------------------------------------------- | ----------- |
| FT temporal (rate, rhythm, hesitations) | ≥ 58 effective fps; full 15 s take                                    | `frame_drops`, duration, `tap_counter` events                     | `frames.bin`, `landmarks.bin`, `quality.json` | Metronome tapping at 2, 3, 4 Hz recovers rate within ±3% | Not started |
| FT amplitude / decrement                | All 21 hand points visible; hand 25–45% of frame height; ~30° view    | `required_landmarks_visible`, `subject_size`, `in_safe_zone`      | `landmarks.bin`                               | Occlusion fixture: partly hidden thumb → RETAKE          | Not started |
| FTF trajectory / accuracy               | Both arms and hands in frame through full extension; 15 s             | `required_landmarks_visible` (pose + both hands), `single_person` | `landmarks.bin`                               | Full-extension fixture: wrists visible ≥ 95%             | Not started |
| FR rotation rate / amplitude            | Elbow + hand visible; ≥ 58 fps; 15 s                                  | `required_landmarks_visible`, `frame_drops`, `rotation_counter`   | `landmarks.bin`, `frames.bin`                 | Known-rate rotation fixture: cycle count exact           | Not started |
| SAW gait (cadence, step, turn)          | Side view; feet visible across the walkway; floor marks visible; 30 s | `side_view`, ankle visibility, `saw_phases`                       | `landmarks.bin` + movement window             | Walk fixture: all 6 phases, boundary error ≤ 0.3 s       | Not started |
| SAW sit-to-stand                        | Chair and whole body visible at start                                 | `required_landmarks_visible` (33 points) at start                 | `landmarks.bin`                               | Rise fixture: rise phase detected                        | Not started |
| FA expressivity                         | Frontal face; even light; 15 s                                        | `face_frontal`, `face_light_balance`, `brightness`                | Face landmarks + blendshapes + `quality.json` | Pose/light fixture: 20° head turn → RETAKE               | Not started |
